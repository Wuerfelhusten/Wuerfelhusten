# Hi, I'm Dennis 👋

I'm 22, based in Germany, and I've been into modding for years.

I enjoy building tools, UI and infrastructure for the games I play. Most of my work is around Bethesda titles, but I'm interested in modding across all kinds of games and occasionally end up working on something completely unrelated.

UI is one of my biggest interests, and I've created a number of Skyrim UI mods using Flash/Scaleform alongside native tooling, SKSE integrations, libraries and API tooling.

I'm the founder of [Modding Forge](https://moddingforge.com/), a community and documentation hub for modding-related projects.

Modding Forge hosts the documentation for all of my related projects. We also host documentation for other modding projects, so if you're looking for a place to host your project's docs, feel free to reach out.

We also run a Discord community:
[discord.gg/pqEHdWDf8z](https://discord.gg/pqEHdWDf8z)
