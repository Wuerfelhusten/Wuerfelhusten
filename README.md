# Hi, I'm Dennis 👋

I'm 22, based in Germany, and I've been into modding for years.

I enjoy building tools, UI and infrastructure for the games I play, mostly around Bethesda titles. UI is one of my biggest interests, and I've created a number of Skyrim UI mods using Flash/Scaleform alongside native tooling, SKSE integrations and other modding infrastructure.

I'm the founder of [Modding Forge](https://moddingforge.com/), a community and documentation hub for modding-related projects. We also host documentation for other projects, so feel free to reach out if you need a place for yours.

## What I usually work on

- UI and UX for game mods
- Skyrim UI development with Flash / Scaleform
- Modding tools, APIs and infrastructure
- Bethesda plugin and modding formats
